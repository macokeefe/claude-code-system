Putting the Standard-Work Data to Work

Sola Lounge · how the times I collected turn into decisions · 2026-06-16

The data isn't a report — it's a tool for making line decisions (headcount, tooling, part quality) from measured time instead of guesswork. Five specific ways it pays off:

1

Lock in what already works as a written standard

Trellis Seat Support: 30 min solo → ~15 min with two people. Connector feeder kept ahead in a buffer → the line never waits on connectors.

Do: Make it a posted rule — two people on Trellis Seat Support on Sola-heavy days, and keep the connector buffer stocked ahead. Protects the gains we already get by habit.

2

Point improvement effort at the step that actually sets the clock

One sofa = ~75 min build / 130 min labor. The two frame steps (Frame Sub-Assembly 19:00 + Frame Assembly 19:00 = 38 min) are more than the rest of the critical path combined.

Do: Build the two frame sub-pieces in parallel (they're independent → ~8.5 min, free) and add a frame-alignment fixture. Build time ~75 → ~60 min with no wasted effort on steps that don't gate the line.

3

Expose the rework that shouldn't exist

Connector Pre-Assembly is ~11–13 min of swapping wrong screws for correct ones (1012943 → 40204) plus a re-orientation — every Sola, every config.

Do: Take the numbers to purchasing — if connectors arrive with the correct screws, this step nearly disappears across the whole Sola family. Data turns a vague complaint into a costed supplier ask.

4

One source of truth for staffing & throughput

Every step is timed, with dependencies, sizes, and shared steps mapped — so headcount, line balance, and units/shift come straight from the model.

Do: Use it to answer "how many people / how many per shift" with a number, and reuse the shared steps (connectors, frame prep) so a fix on one config improves all three — and the same method extends to Meritage and the next product.

5

Keep it current and complete

Times already corrected (Trellis 51 → 30). One step on the Base config still blank; configs don't fully line up for a clean comparison yet.

Do: Finish the last few entries and update times as the floor changes, so the data stays the trusted basis for decisions instead of going stale.

Bottom line: measured time, not guesswork — standards locked in, effort aimed at the real constraint, rework pushed back to the supplier, and one model that answers staffing for every config and product.
