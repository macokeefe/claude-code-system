Observations Made During Timing

Three Issues Found While Collecting Data

Step 2
Supplier ships wrong screws
✓ Timed directly — 3:15 per chair
Every single sofa requires correcting supplier errors before assembly can proceed: wrong screws on classic connectors, wrong screws on directional connectors, and wrong orientation on one left connector. This adds 3 minutes 15 seconds of rework to every chair with zero value added. Simple to fix — it's a supplier specification issue.

Step 12 → 13
Bars attached out of sequence
⚠ Observed — cost documented, frequency not yet measured
When bars are not ready before the chair reaches the weaving table, both weavers must wait while bars are attached. The team has documented ~44 worker-minutes of idle time when this occurs. Each event adds 23 minutes to that chair's build time. How often this happens still needs to be tracked over several weeks.

Step 13
2-operator weave model leaves 1 idle
✓ Observed — 1 weaver idles ~6 min per chair
Three sides need to be woven. With 2 operators, sides 1 and 2 are done simultaneously, then one operator weaves side 3 while the second sits idle. This happens on every chair. The task structure doesn't match the staffing — 3 sides for 2 people means the third side always has idle labor.

Based on Documented Times — Modeled Improvement

What the Data Suggests is Possible

Using the documented step times, a simulation was run to model different staffing approaches for Steps 12 and 13 (the parallelizable steps). These are projections based on measured data — not guesses — but actual implementation decisions require input from operations.

Scenario Change from current Modeled cycle time vs. today
Current 2 weavers, bars sequential, sometimes out-of-sequence 64–87 min Baseline
Option A 3 bar ops + 3 weavers (1 per side, parallel) ~67 min Consistent, no delay risk
Option C ← Suggested Option A + supplier fixes screw spec (eliminates 3:15 waste) ~65 min −~20% vs. delayed state

Note: modeled using 1,000 simulation runs with documented step times as inputs. Staffing decisions are for operations to assess.
